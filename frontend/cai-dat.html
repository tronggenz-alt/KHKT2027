02

Key Gemini của bạn

Dán key lấy ở aistudio.google.com (xem mục 03 nếu chưa có).

Key hiện tại

…

App chưa tạo được khoá mã hoá (data/app_secret.key) nên chưa lưu được key (key phải được mã hoá trước khi lưu). Chủ app kiểm tra quyền ghi thư mục data/. Vẫn bấm “Kiểm tra key” được.
  • Key được mã hoá trước khi lưu. App không bao giờ gửi lại key cho trình duyệt hay ghi vào log – chỉ hiện 4 ký tự cuối.
  • Có key riêng thì mọi bài giải dùng key của bạn. Key lỗi hoặc hết hạn mức thì app báo lỗi, không tự chuyển sang key của chủ app.
  • “Kiểm tra key” gọi thử một yêu cầu rất nhỏ tới Gemini (tốn 1 lượt). Ô trống thì kiểm tra key đã lưu. “Lưu key” cũng kiểm tra trước khi lưu.

03

Cách lấy key Gemini

Miễn phí, khoảng 1 phút, chỉ cần một tài khoản Google.

  1. BƯỚC 01

    Mở Google AI Studio

    Vào trang aistudio.google.com/apikey và đăng nhập bằng tài khoản Google (dùng chính tài khoản đang đăng nhập app cũng được).

    aistudio.google.com/apikey
    Google AI Studio·Get API keySign in
  2. BƯỚC 02

    Bấm “Create API key”

    Ở trang API keys, bấm nút Create API key (Tạo khoá API). Lần đầu Google có thể hỏi đồng ý điều khoản – bấm đồng ý.

    aistudio.google.com/apikey
    API keys＋ Create API key
  3. BƯỚC 03

    Chọn dự án rồi sao chép key

    Chọn một dự án Google Cloud có sẵn (hoặc để AI Studio tự tạo dự án mới) → Create. Key hiện ra: bấm Copy. Key là một chuỗi dài, thường bắt đầu bằng AIza.

    aistudio.google.com/apikey
    AIzaSy•••••••••••••••••••••••••Xk3Q⧉ Copy
  4. BƯỚC 04

    Dán vào app

    Lên mục 02, dán vào ô, bấm Kiểm tra key rồi Lưu key. Xong – từ giờ mọi bài giải dùng key của bạn.

Lưu ý

  • Gói miễn phí của Google giới hạn số lượt gọi mỗi phút và mỗi ngày cho từng mô hình (xem ở AI Studio → Usage & limits). Một bài giải dùng khoảng 3–8 lượt, đề khó (HSG) nhiều hơn.
  • Muốn hạn mức cao hơn hoặc dùng Gemini Pro cho đề khó: bật thanh toán (Billing) cho dự án của key trong AI Studio.
  • Giữ key bí mật như mật khẩu. Nếu lộ key: vào trang API keys xoá key cũ, tạo key mới rồi lưu lại ở đây.
  • Hướng dẫn chính thức của Google: ai.google.dev/gemini-api/docs/api-key.

06

Key Claude

Nhập key do chủ app cung cấp để mở khoá Claude: trên trang giải sẽ có công tắc “Dùng Claude” – bật thì bài đó (và mục Cơ chế) giải bằng Claude, có giới hạn số bài mỗi ngày. Không nhập key thì bài giải dùng Gemini như bình thường.

API key Claude của bạn

Có API key Claude riêng (platform.claude.com → API keys) thì dùng được Claude mà không cần Key Claude chung: bài giải gọi bằng key của bạn, không tính vào lượt Claude của app. Key được mã hoá khi lưu, app chỉ hiện 4 ký tự cuối.
